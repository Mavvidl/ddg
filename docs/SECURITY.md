# Security policy

DDG is an analysis tool, not a malware removal engine. It should not kill, quarantine or modify a process in the MVP.

Report security issues privately to the repository maintainer rather than publishing exploit details in an issue. Remove secrets, API keys and personal data from reports before sharing them.

The online lookup feature is opt-in and the MVP sends only the executable hash to VirusTotal. Process paths and command lines can contain sensitive information and are kept local unless the user explicitly exports or shares the report.
